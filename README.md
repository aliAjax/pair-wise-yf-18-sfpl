# hxyfront-62006 珠宝镶嵌宝石分拣

面向珠宝镶嵌工作室的宝石分拣前端系统，展示页即「分拣台」。所有登记资料与历次调整只保存在当前浏览器（localStorage），不上传服务器。

## 分拣规则

- **批次归组**：录入石头时填写订单号与分拣批次号，分拣台按「待补区 / 待镶嵌 / 已送镶」分区，区内按批次分组展示。
- **重复编号**：同一批次内宝石编号唯一，重复录入会被拒收并提示，先登记的资料保留。
- **待补区**：尺寸或镶嵌位置没填的石头先进入待补区；资料补齐后自动转入待镶嵌，再手动「送镶嵌」。
- **送镶后改动退回**：已送镶的石头若修改克拉重量或形状，会退回待补区核对，原值、新值与修改时间写入「历次调整」；核对无误可重新送镶。
- **筛选**：分拣台支持按形状与状态筛选（另附编号/批次/订单/备注关键字搜索）。
- **订单视图**：按订单展开各批次，汇总每批次待镶嵌、待补、已送镶数量与合计克拉。
- **单颗详情**：点开石头可见全部资料、缺陷备注、镶嵌位置示意图、登记/送镶时间及历次调整时间线，并可补齐或修改资料。

## 技术栈

React 19 + Vite 7 + TypeScript（严格模式），无后端依赖。
