# 宝石分拣台 · 珠宝镶嵌工作室

面向珠宝镶嵌工作室的混单分拣前端：宝石按批次归组登记，资料留在本机（localStorage），覆盖待补、送镶、退回复核的完整流转。

## 功能规则

- **本机存储**：所有登记与修改只保存在当前浏览器的 localStorage，不上传任何服务器。
- **批次归组 + 重复编号**：同一批次内宝石编号唯一；重复编号以**先登记的记录为准**，后到的录入会被拦截并提示。
- **待补区**：尺寸或镶嵌位置任一未填，登记后自动进待补区；补齐后进入「待镶嵌」队列。
- **送镶退回**：已送镶的石头若修改**克拉重量**或**形状**，自动退回待补区，原值与修改时间记入历次调整。
- **筛选**：按形状与状态筛选（另支持编号/批次/订单关键字检索）。
- **订单视图**：按订单 → 批次汇总待补 / 待镶嵌 / 已送镶数量与克拉合计。
- **单颗详情**：缺陷备注、镶嵌位置示意图、完整的历次调整时间线（含原值 → 新值与时间戳）。

## 技术栈

React 19 + Vite + TypeScript（无额外运行时依赖）

```bash
npm install
npm run dev
```
